## 1. 域名还差最后一步（1 分钟）

**现状**：`nas.20061028.xyz` 在权威 DNS 里仍然是 **NXDOMAIN**（我用 Google/Cloudflare 的公共 DNS 都查过）。
隧道里那条「已发布的应用程序」存在，但它**没有生成 DNS 记录**。浏览器报 `ERR_CONNECTION_CLOSED`
多半是运营商 DNS 把 NXDOMAIN 劫持成了一个错误地址，所以看起来"连上了又断开"。

**二选一：**

- **A（推荐）** 隧道 → 路由 → 添加路由时选「**公有主机名 / Public hostname**」（不是"已发布的应用"），
  保存后 Cloudflare 会自动建 CNAME。
- **B（最稳）** 手动加 DNS：左侧 **DNS → 记录 → 添加记录**

  | 类型 | 名称 | 目标 | 代理状态 |
  |---|---|---|---|
  | `CNAME` | `nas` | `0aba8d3a-616c-41c4-a1ad-549e4ad716e2.cfargotunnel.com` | 已代理（橙色云） |

**验证**：

```powershell
Resolve-DnsName nas.20061028.xyz     # 应返回 104.x 或 172.67.x
```

通了之后：先过 Cloudflare Access（如果有策略）→ 到 `/setup` 建站长账号 → 进玄关。
