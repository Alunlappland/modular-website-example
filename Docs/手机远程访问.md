# 手机远程访问这台电脑（公网手段）

> 目标：不在 ZeroTier 上赌运气，用「电脑主动向外连」的方式让手机随时接管 DSH。
> 写于 2026-11-21，对应插件 `ds-harness-remote@0.6.5`（已在这台机器装好）。

---

## 方案一（推荐）：DS Harness Remote —— 已安装

### 它是什么
一个 DSH 插件。装上后这台电脑作为 **Host** 主动向外建立一条端到端加密的通道，
**不需要公网 IP、不需要开端口、不需要路由器映射**，手机从任何网络都能连回来。
默认走作者托管的中继 `https://dsh.r2049.cn`（国内可直连），优先尝试局域网 / P2P / TURN，最后才回落中继。

### 电脑端：登录一次（1 分钟）

1. 打开 DSH 界面，在侧边栏/插件区找到 **Remote（DS Harness Remote）** 入口
   （刚安装的插件会出现在插件列表里；找不到就重启一次 DSH Desktop）。
2. 点开后选择登录方式：**知乎 / GitHub / Google** 授权，或账号密码。
3. 登录成功后，这台电脑会显示为**在线 Host**，可以选工作区。
4. 建议在 Host 列表里打开 **「仅被控」**：这台机器不再能看到/控制你账号下的其他 Host。

> 我这边已经确认：插件已加载（DSH 工具列表里出现了 remote_* 工具），
> 服务器 `dsh.r2049.cn` 也可达；现在只差你在界面上授权登录这一步。

### 手机端：三选一

| 方式 | 做法 | 适合 |
|---|---|---|
| **浏览器**（最省事） | 打开 <https://dsh.r2049.cn>，登录同一账号 → 选这台电脑 → 打开工作区 | 临时用、不想装 App |
| **dsh-go** | 已下载的 `dsh-go-1.2.0-arm64.apk` 安装后登录同账号，远程主机列表里选这台 | 长期用、要拍照/语音/手机操控 |
| **官方安卓 App** | [ds-harness-remote Releases](https://github.com/liguobao/ds-harness-remote/releases/latest) | 只想要远程，不要本地引擎 |

### 安全边界
- 全程端到端加密（Noise IK / ChaChaPoly），中继只转发密文，读不到对话与文件内容。
- 只有**同一账号**的设备能连；可随时在面板里移除设备、撤销授权。
- 远程终端以 Host 用户身份运行，和本地权限一致——别把账号借人。

### 不想要了怎么卸
插件管理里停用或移除 `ds-harness-remote`，或命令行：
```powershell
# 在 DSH 里通过插件管理移除即可，不需要手动删目录
```

## 方案二：Cloudflare 隧道 + 浏览器 SSH（备选）

已经有 Cloudflare 隧道，所以也能把 SSH 暴露出去，然后用**手机浏览器**开终端：

1. 先在本机装 SSH 服务（管理员窗口）：
   `powershell -ExecutionPolicy Bypass -File .\Tools\enable-ssh-remote.ps1`
2. Cloudflare 控制台 → Zero Trust → Access → Applications → 新建 **Self-hosted** 应用：
   - 域名 `ssh.20061028.xyz`，类型选 **SSH**，策略限你自己邮箱
3. 隧道 → 路由 → 添加 `ssh.20061028.xyz` → 服务 `ssh://localhost:22`
4. 手机浏览器打开 `https://ssh.20061028.xyz`，Cloudflare 会渲染一个网页终端，登录后直接跑 `dsh` / DSH-TUI。

> 好处：不装任何 App，OS 级别访问。
> 坏处：网页终端体验一般，且比方案一多暴露一个面。

## 方案三：隧道访问站点（正在修）

`nas.20061028.xyz` 目前 DNS 里还没有记录（权威 DNS 返回 NXDOMAIN），
在 Cloudflare → DNS 里加一条 CNAME 到 `<隧道ID>.cfargotunnel.com`（橙色云）即可。
通了之后手机浏览器直接看站点，配合「对话」板块用 chat-demo。
