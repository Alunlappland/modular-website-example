## 二、需要你动手的（按重要性）

1. **填 kopia 仓库密码**：登录 `/backup` → 「仓库密码」保存（就是 `H:\restore` 那个仓库的密码）。
   不填的话，每天 12:00 的计划任务会失败（日志会记 failed）。
2. **重传昨天被我误删的三个文件**（两张图 + 一个 4.3MB 视频）——文件已不可恢复。
3. **装 Syncthing**（管理员）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\Users\manifld\website\Tools\install-syncthing.ps1
   ```
   把脚本打印的 API Key 填进 `Main\conf\appsettings.json` 的 `sync:syncthing:apiKey`，刷新 `/sync`。
4. **给 R2 凭据**（桶名 + Access Key + Secret），我才能接 rclone 镜像；不然备份只有本机一份。
5. **装成 Windows 服务**（管理员），让站点不再依赖我的会话：
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\Users\manifld\website\Tools\install-service.ps1
   ```
   装完把启动目录里的 `Genkan.vbs` 删掉，避免重复启动。
